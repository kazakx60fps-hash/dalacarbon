# DalaCarbon AI — мобильді қосымша (Flutter)

Сайттағының бәрі телефонда, **сол бір серверге** қосылады (Flask JSON API `/api/v1`):

| Бөлім | Не бар |
|---|---|
| Заставка | Спутник алқаптардың үстінен ұшады, NDVI түсімен бояйды; сақталған кіру болса — бірден басты бет |
| Кіру / Тіркелу | Нақты аккаунт, сайттағыдай тексеру мен қате мәтіндері, «Мені есте сақта», құпиясөзді қалпына келтіру (хат) |
| Шолу | Сәлемдесу, хабарламалар, іздеу, маусым сақинасы (68%), апта күнтізбесі, KPI, жылдам әрекеттер, график 3/6/12 ай, учаскелер сақинасы |
| Талдау | KPI, 12 айлық секвестрация, 1 гектардан табыс (фермер 75% / платформа 25%) |
| Алқаптар | PostgreSQL-дегі нақты учаскелер: қосу (бағалау бірден), өшіру (растаумен) |
| Карта | NDVI (NASA MODIS немесе Sentinel-2), Қазақстан шекарасы, облыс, маусым, спутник/карта фоны, мөлдірлік |
| Тағы | Кесте (ай күнтізбесі), Хабарлар (оқу), Хабарламалар, Белсенділік, MRV есебі, Баптаулар, Шығу |

Кіру токені Android Keystore-да (`flutter_secure_storage`) сақталады; серверде тек хеші, 30 күн жарамды,
құпиясөз ауысса — жабылады. Google арқылы кіру әзірге тек сайтта.

## Іске қосу

1. Сайттың серверін **жаңа кодпен** іске қосыңыз (API соған кірген):
   ```powershell
   cd C:\Users\TechHub\Desktop\dalacarbon
   .venv\Scripts\python run.py
   ```
2. Эмуляторды ашып, қосымшаны іске қосыңыз:
   ```powershell
   cd C:\Users\TechHub\Desktop\dalacarbon\mobile
   flutter run
   ```
   Эмулятор компьютердің серверіне `http://10.0.2.2:5000` арқылы қосылады (әдепкі).

**Нақты телефонда:** телефон мен компьютер бір Wi-Fi-да болсын, серверді `run.py` ішінде `host="0.0.0.0"`
етіп қосыңыз, сосын қосымшада кіру бетінің оң жақ жоғарғы белгісі (немесе Баптаулар → Сервер мекенжайы)
арқылы `http://<компьютердің-IP>:5000` жазыңыз. Басқа серверге бірден құрастыру:
`flutter run --dart-define=API_BASE=http://192.168.1.5:5000`.

Debug нұсқасы шифрсыз HTTP-ге рұқсат етеді (тек `android/app/src/debug`). Нақты жариялау үшін сервер HTTPS болуы керек.
